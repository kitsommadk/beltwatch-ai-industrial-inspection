# Persisted pair metrics

- `gap_px`: horizontal pixel gap between Belt A right edge and Belt B left edge;
- `belt_a_center_x_px`, `belt_b_center_x_px`: image-coordinate lane centers;
- `center_distance_px`: Belt B center minus Belt A center;
- `total_occupied_span_px`: left edge of A through right edge of B.

All remain pixel-space software observations pending physical calibration/qualification.

# GitHub publishing checklist

Suggested repository name: `beltwatch-ai-industrial-inspection`

Suggested description:

> Local-first React + FastAPI industrial inspection pilot with event review,
> audit logging, secure edge deployment design, and an explicit simulated-to-live
> vision integration boundary.

Suggested topics:

`fastapi`, `react`, `python`, `computer-vision`, `edge-computing`,
`industrial-ai`, `physical-ai`, `sqlite`, `docker`, `human-in-the-loop`

Before publishing:

- Confirm the repository is public.
- Confirm no `.env`, database, credentials, real footage, or customer records are included.
- Add the repository URL to the resume and application.
- Pin the repository on the GitHub profile.
- Keep the About-page description concise and add the Phase 1 demo URL.
- Do not label the project “production AI” until live camera/model validation is complete.

The repository intentionally has no open-source license. Public visibility lets
recruiters inspect the work but does not grant reuse rights by default. Add a license
later only if that is an intentional business decision.
